# Как добавить новый товар в каталог PRISM

Каталог организован по системе **"Папка = Товар"**.  
Каждый товар — это самодостаточная директория внутри категории.

---

## 📁 Структура

```
Catalog/
├── Plastic/             ← категория "Пластик"
│   ├── monstera-stand/  ← ID товара (slug, маленькими буквами через дефис)
│   │   ├── model.glb    ← 3D модель
│   │   ├── preview.webp ← превью для каталога (опционально)
│   │   └── info.json    ← характеристики товара
│   └── ...
├── Wax/                 ← категория "Воск"
└── Epoxy/               ← категория "Эпоксидка"
```

---

## ✅ Как добавить товар (пошагово)

### Шаг 1 — Создайте папку
Имя папки = **ID товара** (slug): маленькие буквы латиницей, слова через дефис.

**Примеры:**
- `monstera-stand`
- `liberty-headband`
- `candle-geo`

### Шаг 2 — Положите модель
Положите `.glb` файл в папку и назовите его `model.glb`.

```
Catalog/Plastic/candle-geo/
    └── model.glb
```

**Готово! Товар уже появится в каталоге** (пока без превью и с заглушкой ⬡).

---

### Шаг 3 — Заполните `info.json`

Создайте файл `info.json` в папке товара:

```json
{
  "name": "Свеча \"Гео\"",
  "price": 290,
  "sizes": "⌀60 × 90 мм",
  "description": "Геометрическая свеча с необычной формой.",
  "colors": ["matte-white", "gloss-black", "silk-gold"]
}
```

| Поле         | Обязательное | Описание                                              |
|:-------------|:------------:|:------------------------------------------------------|
| `name`       | ✅            | Название, отображаемое на сайте                       |
| `price`      | ✅            | Цена в гривнах (число)                                |
| `sizes`      | ❌            | Размеры. Если пусто — вьювер вычислит автоматически   |
| `description`| ❌            | Короткое описание для страницы товара                 |
| `colors`     | ❌            | Список доступных цветов (ID из таблицы ниже). Если не указан — показываются все цвета |

---

### Шаг 4 — Добавьте превью (когда будет готово)

Просто положите файл превью рядом с `model.glb`:

```
Catalog/Plastic/candle-geo/
    ├── model.glb
    ├── preview.webp  ← (или .png, .jpg)
    └── info.json
```

Превью **подтянется автоматически** без каких-либо изменений в коде.

## 🎨 Доступные цвета (`colors`)

| ID                | Цвет              | Материал    |
|:------------------|:------------------|:------------|
| `matte-white`     | Белый             | PLA матовый |
| `matte-black`     | Чёрный            | PLA матовый |
| `matte-red`       | Красный           | PLA матовый |
| `matte-green`     | Зелёный           | PLA матовый |
| `matte-blue`      | Синий             | PLA матовый |
| `matte-beige`     | Бежевый           | PLA матовый |
| `gloss-white`     | Белый             | PETG глянец |
| `gloss-black`     | Чёрный            | PETG глянец |
| `gloss-yellow`    | Жёлтый            | PETG глянец |
| `silk-gold`       | Золотой           | PLA шёлк    |
| `silk-rose`       | Розовый           | PLA шёлк    |
| `silk-mint`       | Мятный            | PLA шёлк    |
| `clear-teal`      | Бирюзовый         | PETG-T прозрачный |

---

## 🗑️ Как удалить товар

Просто удалите папку товара. Он исчезнет из каталога автоматически.

---

## 🏷️ Как добавить новую категорию

Создайте новую папку в `Catalog/`:

```
Catalog/
    └── Wood/    ← новая категория "Дерево"
```

Чтобы она отображалась с красивым названием — добавьте её в `CATEGORY_NAMES` в файле `api/catalog.js`:

```js
const CATEGORY_NAMES = {
  'plastic': 'Пластик',
  'wax': 'Воск',
  'epoxy': 'Эпоксидка',
  'wood': 'Дерево'    // ← добавьте сюда
};
```

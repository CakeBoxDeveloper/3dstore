# Структура каталога

Каждый товар — папка внутри категории:

```
Catalog/
  Plastic/
    my-product/
      model.glb        ← обязателен (без него товар не появится)
      preview.webp     ← опционально (статичная картинка-превью)
      info.json        ← мета-данные
```

## Пример info.json

```json
{
  "name": "Назва товару",
  "price": 350,
  "sizes": "120 × 90 × 85 мм",
  "description": "Короткий опис.",
  "colors": ["matte-white", "matte-black", "matte-green"],
  "accentColors": ["#1a3d1a", "#2d4a1e", "#3a5c2a"]
}
```

## Поля info.json

| Поле          | Тип             | Описание                                      |
|---------------|-----------------|-----------------------------------------------|
| `name`        | string          | Назва товару                                  |
| `price`       | number          | Ціна в гривнях                                |
| `sizes`       | string          | Розміри (довільний текст)                     |
| `description` | string          | Опис                                          |
| `colors`      | string[]        | ID кольорів зі списку матеріалів              |
| `accentColors`| string[]        | HEX кольори для 3D превью (1–4 штуки)        |

## Категорії

| Папка     | Назва на сайті    |
|-----------|-------------------|
| `Plastic` | 3D Печать         |
| `Wax`     | Свічки            |
| `Epoxy`   | Епоксидна смола   |

## Як додати новий товар

1. Створи папку `Catalog/Plastic/my-product/`
2. Поклади туди `model.glb`
3. Створи `info.json` за шаблоном вище
4. (опц.) Поклади `preview.webp` для статичної картинки
5. Готово — товар з'явиться автоматично
